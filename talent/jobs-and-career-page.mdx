---
title: "Prepare and publish a job"
description: "Create a job, review its application form, and check the public career page."
---

Prepare a job before publishing it so applicants receive an accurate description and a working application form. Use an account authorized to create jobs in the active organization.

1. Open **Jobs** and start a new job.
2. Enter the role details and location requested by the form. Write a description that explains the work and requirements.
3. Review the application questions and any evaluation criteria configured for the role. Request only information needed for recruitment.
4. Use the preview to check the candidate-facing description and application journey.
5. Resolve any missing requirements shown by the app before publishing. If a role limit prevents publication, ask your organization administrator to review the account rather than repeatedly submitting.
6. Open the public job link and check the title, location, description, and application form before sharing it.

**Expected result:** the job has the intended state and its public link presents the correct employer and application details. A saved draft is not the same as a published role.

## Career-page settings

An authorized administrator can review the organization’s career-page settings. Check branding and public employer details before distributing the link. Coordinate changes to public roles with the team handling existing applications.

If publishing fails, preserve the job text and read the validation message. Do not delete a job with active applications just to retry publication.
