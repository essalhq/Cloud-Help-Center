title: "Manage Project members and settings"
description: "Understand workspace roles, invitations, modules, and missing access."
---

Project uses workspace roles. Check the active workspace before inviting someone or changing a setting.

| Role | Typical controls |
| --- | --- |
| ADMIN | Manage workspace and projects, create and edit work, and use administrative deletion controls. |
| MEMBER | Create and collaborate; editing an existing task can depend on assignment. |
| VIEWER | View authorized resources with restricted creation, editing, and commenting. |

## Invite a colleague

1. Use the workspace invitation action available to administrators.
2. Confirm the address and choose the appropriate role.
3. Send the invitation and have the recipient open it using their own account.
4. Check membership and the resources they can access.

## Workspace settings

An administrator can review workspace settings and enabled modules. Changes can affect every member. Before disabling a module or removing access, coordinate with the people using its content.

If a task cannot be edited, check both the role and its assignment. If a module is absent, check its workspace setting before treating it as an outage. Do not share an administrator account to bypass a missing permission.
