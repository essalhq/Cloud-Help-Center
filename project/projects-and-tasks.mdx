---
title: "Create and manage projects and tasks"
description: "Record work, assign responsibility, and update task progress."
---

Use a project to group related work and a task to describe an actionable piece of it. Check your workspace and permissions before creating or deleting anything.

1. Open the project list and select the create action if your role permits it.
2. Give the project a recognizable name and save it. Open the project’s task view.
3. Create a task with a clear title. Add the description, assignees, status, and date fields offered for your project.
4. Review the saved task in the list or board. Use a calendar view when you need to check scheduled work.
5. Update progress and add relevant discussion or files through the controls available on the task.

**Expected result:** the task appears once in the intended project with the correct owner and state. Check for an existing task before repeating a submission after a connection error.

## Permissions and changes

Administrators can manage the project. Members can create and collaborate, but editing an existing task can depend on whether it is assigned to them. Viewers cannot use all editing controls. See [workspace roles](/project/members-and-settings).

Before deleting a project or task, confirm the resource and read the confirmation. Deletion is different from finishing work or changing its status. Preserve any information your team needs before confirming a destructive action.
