---
title: "Use files, knowledge, and chat in Project"
description: "Choose the right workspace module for documents and team discussion."
---

Project workspaces can expose Drive, knowledge, and Chat modules. Use the modules visible in your workspace; an administrator controls which are enabled.

## Files

1. Open **Drive** in the workspace sidebar.
2. Select the destination before uploading or creating a folder.
3. Check the upload result and open the file to confirm it is the intended version.
4. Use only the sharing actions offered for that resource. Confirm the audience before sending a file link.

## Knowledge

Open the knowledge area or a space in the sidebar. Find an existing page before creating a new one. Keep titles specific and confirm changes have saved before closing. Check the space and page access before placing private information there.

## Chat

Open **Chat**, select the intended conversation, and review its participants before sending a message or attachment. Messages and task comments have different contexts; use the task’s discussion for decisions that need to stay with the work.

If a module is missing, ask an administrator whether it is enabled for your workspace. If a file or page is denied, verify resource sharing as well as membership. Preserve unsaved text before refreshing and follow [common troubleshooting](/troubleshooting/common-problems).
