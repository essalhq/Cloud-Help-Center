---
title: "Start using Essal Project"
description: "Choose a workspace and find projects, tasks, files, knowledge, and time."
---

Essal Project organizes work inside a workspace. Projects contain tasks, while enabled workspace modules provide files, knowledge, chat, and time tracking.

1. Sign in with your invited account and select the intended workspace.
2. Review the projects in the sidebar. Open an existing project before creating a new one.
3. Choose the available list, board, or calendar view to find the work you need.
4. Read a task’s title, status, assignees, and due date before making changes.
5. Complete your first task with [projects and tasks](/project/projects-and-tasks).

**Expected result:** you can find your team’s project and understand which task you own. A project missing from your sidebar can indicate a different workspace or insufficient access.

Use [files, knowledge, and chat](/project/files-knowledge-and-chat) for supporting work, and [time tracking](/project/time-tracking) for recording effort. Module availability depends on workspace configuration; a hidden module is not necessarily a broken page.

Ask an administrator about [membership and settings](/project/members-and-settings) if you need to create resources or manage the workspace.
