---
title: "Resolve common app problems"
description: "Check sign-in, permissions, saving, and connectivity before contacting support."
---

First identify which app, organization, and action are affected. A missing permission, interrupted connection, and service incident require different fixes.

| Symptom | What to check |
| --- | --- |
| Cannot sign in | App link, invited email, latest sign-in email, and account status. Follow [sign-in help](/getting-started/sign-in). |
| Missing page or button | Workspace, role, resource sharing, and modules enabled for that workspace. Ask its administrator. |
| Change does not appear | Look for a save confirmation or error, confirm the resource and workspace, then reopen it. Preserve unsaved text before refreshing. |
| Upload fails | Review the field’s displayed format and size requirements, connection, and permissions. Try a small permitted file without sensitive data. |
| Shared link is denied | Confirm the intended recipient, sign-in requirement, expiry or revocation, and resource permissions. |
| Access scan is denied | Check the displayed result, badge status, schedule, zone, and device synchronization. See [scan results](/access/check-in-devices/understanding-scan-results). |

Do not repeatedly submit an action that might create duplicate records or payments. Check for an existing result first.

For possible outages, check [service status](/introduction/status). For an unresolved issue, [send a support request](/introduction/contact). Do not clear browser storage on an offline Access device until pending scans are synchronized.
