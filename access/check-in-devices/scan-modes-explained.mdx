Choose the mode appropriate to the check you are performing. QR verification and recording a photo are different operations.

## Badge Mode (QR Scanner)

1. Select **Badge** in the Scan tab and allow camera access.
2. Present a supported employee or guest QR credential to the camera.
3. Read the displayed result and reason before deciding what to do next.
4. If the code cannot be read, check lighting, focus, and the physical or on-screen QR. Use the manual entry offered by the app when appropriate.

The device checks identifiers and access rules using its available connection and synchronized data. See [scan results](/access/check-in-devices/understanding-scan-results) and [offline mode](/access/check-in-devices/offline-mode).

## Photo Mode (Camera Capture)

1. Select **Photo** and capture the image only when your organization authorizes it.
2. Review the preview and supply a reference identifier and note when needed.
3. Confirm the record and check the result. A supplied reference can run credential verification as well.

**A photo without a reference is a recorded capture, not independent proof of identity or permission to enter.** Follow your organization’s verification procedure before granting access.

## AI Face Mode

The current check-in interface displays an unavailable message for AI face scanning. Do not depend on that mode for identity matching, automatic approval, or offline facial recognition. Use the supported Badge or Photo workflow and your organization’s authorized manual checks.

## If a mode is missing

The device policy can restrict available modes. Ask an administrator to review the device configuration instead of changing another organization’s settings. For a camera problem, use [device troubleshooting](/access/check-in-devices/device-troubleshooting).


## Need help?

If an action is missing, check [your role](/access/getting-started/understanding-user-roles) and the active organization. Use [troubleshooting](/troubleshooting/common-problems) or [contact support](/introduction/contact) with the exact message.
