---
title: "Set up Mail rules and signatures"
description: "Review automated mailbox actions and choose the correct signature for an identity."
---

Rules automate supported mailbox actions. Signatures add reusable information to outgoing messages. Check the email identity you are configuring before saving either one.

## Rules

1. Open the mailbox settings and its rules area.
2. Review existing rules before adding another. Choose the conditions and actions offered by the rule form.
3. Check that the condition matches only the messages you intend to affect. Review the effect of any delete, move, or similar action before enabling it.
4. Save the rule, confirm its enabled state, and check its behavior with a non-sensitive message.

If messages move unexpectedly, review enabled rules and their conditions before creating a compensating rule.

## Signatures

1. Open signature settings for the intended identity.
2. Create or edit the signature with approved contact information.
3. Save and select the intended signature or default option offered by the app.
4. Start a new message from that identity and review the result before sending.

**Expected result:** only the intended mailbox behavior changes and outgoing messages use the approved signature. Keep private personal details out of shared signatures. If a rule or signature does not appear, check the identity, saved state, and access before recreating it.
