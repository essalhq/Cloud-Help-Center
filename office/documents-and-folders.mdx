---
title: "Create and organize Office documents"
description: "Create resources in the right space and confirm their location and save state."
---

Choose a writable space and folder before creating a resource. This keeps work discoverable and avoids sharing it with the wrong audience.

1. Open the destination space or folder.
2. Use the create menu and choose one of the document types shown, or create a folder to group related work.
3. Enter a specific name and confirm creation.
4. Open the resource, make the intended changes, and check any connection or save message before closing.
5. Return to the resource list and verify the name and location. Search existing resources before creating a replacement for something that seems missing.

**Expected result:** the document is visible in the selected location and can be reopened by your account.

If creation is disabled, the space may not be writable for you. If a document opens read-only, ask its owner to review [sharing permissions](/office/sharing-and-permissions).

Moving, renaming, and deleting are different actions. Review the selected item and destination before confirming. When deleting, check whether a folder contains work other people still need; see [Trash and recovery](/office/trash-and-recovery).
