---
title: "Import and export Office files"
description: "Use supported formats and inspect the result before replacing an original."
---

Office’s import and export options depend on the resource type and the capabilities available in your workspace. Use the formats shown by the app rather than assuming every format is supported.

## Import

1. Keep a copy of the original file.
2. Select the destination space or use the import action offered for the document type.
3. Choose a supported file and wait for the app’s result.
4. Open the imported resource and review important content, formatting, formulas, and layout as applicable.
5. Share it only after confirming the result and its permissions.

## Export

1. Open the correct document and review the content to include.
2. Use the available export or download action and choose an offered format.
3. Open the downloaded file in its intended viewer and check the sections that matter to your workflow.

**Expected result:** the imported or exported file opens and contains the intended content. Conversion can change presentation or unsupported features; retain the original until you have checked the result.

If a format is absent or conversion fails, record the document type, selected format, and error for [support](/introduction/contact). Do not send a confidential original without agreeing a suitable support channel.
