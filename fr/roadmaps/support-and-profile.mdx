---

Utilisez l’assistance du portail, si activée, pour les questions qui ne doivent pas figurer dans un tableau public. Vérifiez l’organisation propriétaire du portail.

1. Connectez-vous si nécessaire et ouvrez l’assistance.
2. Recherchez une conversation existante sur le même problème.
3. Décrivez le produit, l’action, l’erreur et l’heure. Ajoutez uniquement les informations nécessaires.
4. Envoyez avec les commandes proposées et vérifiez la présence du message dans le bon fil.
5. Revenez au fil pour lire les réponses au lieu de publier les informations privées en commentaire public.

## Profil et préférences

Utilisez les paramètres du compte pour vérifier le profil et les notifications. Contrôlez l’enregistrement après modification. Le profil du portail est distinct d’une adhésion ou d’une fiche employé gérée dans une autre application.

Si l’assistance du portail manque ou reste inaccessible, utilisez [le contact Essal](/fr/introduction/contact). N’envoyez pas de mot de passe, code ni identifiant de prestataire. En cas d’urgence de sécurité, suivez aussi la procédure interne.
