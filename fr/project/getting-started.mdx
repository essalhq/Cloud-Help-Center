---
title: "Commencez avec Essal Project"
description: "Choisissez un espace et retrouvez projets, tâches, fichiers, connaissances et temps."
---

Essal Project organise le travail dans un espace. Les projets contiennent des tâches ; les modules activés proposent les fichiers, les connaissances, le chat et le suivi du temps.

1. Connectez-vous avec le compte invité et sélectionnez le bon espace.
2. Consultez les projets dans la barre latérale. Ouvrez un projet existant avant d’en créer un autre.
3. Utilisez la vue liste, tableau ou calendrier disponible pour retrouver le travail.
4. Lisez le titre, l’état, les responsables et l’échéance d’une tâche avant de la modifier.
5. Réalisez une première tâche avec [les projets et tâches](/fr/project/projects-and-tasks).

**Résultat attendu :** vous retrouvez le projet de l’équipe et identifiez votre tâche. Un projet absent peut relever d’un autre espace ou d’un droit manquant.

Consultez [les fichiers, connaissances et chat](/fr/project/files-knowledge-and-chat) pour les éléments associés et [le suivi du temps](/fr/project/time-tracking) pour enregistrer l’effort. Les modules dépendent de la configuration ; un module masqué n’est pas nécessairement en panne.

Demandez à un administrateur de vérifier [l’adhésion et les paramètres](/fr/project/members-and-settings) si vous devez créer des ressources ou gérer l’espace.
